# 京华三进 · 内容优化规划

> **2026-10-18 修正：** 阶段一“院落生活陈设”已撤销——鸡舍、晾衣、猫、鸟笼等与书香门第的气质不符。项目转向“附属花园/跨院”方案，见 [四合院-附属花园规划](四合院-附属花园规划.md)。本文件保留为内容规划的背景资料。

## 1. 目标

当前版本建筑与空间关系已基本稳定，但院子仍偏“样板间”：有树、有水缸、有石桌，却缺少日常生活痕迹和动物。内容优化不改变建筑骨架，先增加“有人住”的细节，再逐步扩展到室内、季节和地域变体。

原则：

- **先生活，后装饰**：优先加有功能逻辑的物件，不随机填满空地。
- **成组布置**：月台一组、廊下一组、院心一组、后院服务一组，避免散点。
- **不堵动线**：门洞、廊口、台阶、甬路、侧夹道保持净宽。
- **窄缝不利用**：厢房山墙外 0.6 m 是散水，不放盆栽和杂物。
- **低模优先**：先静态/微动态，动物不做复杂骨骼动画。
- **可复用**：陈设和动物做成可复用内容包，为江南、山西、河南院落准备。

## 2. 当前内容判断

- 建筑：北京三进四合院，硬山合瓦、抄手游廊、垂花门、月台、侧夹道已成形。
- 室内：五个重点房间精装，其余简装。
- 院子：海棠、石榴、枣树、水缸、石桌、少量盆栽；没有动物。
- 结论：**建筑精装，内容简版偏中配**。

## 3. 阶段一：院落生活层（已撤销）

### 3.1 范围

只加院子、廊下、月台、侧夹道、后院的陈设与动物；不改建筑、不改平面、不改室内大件家具。

### 3.2 陈设清单

| 组团 | 内容 | 位置 | 作用 |
|---|---|---|---|
| 廊下 | 坐凳、鸟笼 | 东西游廊靠厢房一侧 | 休息、养鸟、生活气 |
| 院心 | 荷花缸金鱼 | 现有水缸内 | 夏日院心焦点 |
| 月台 | 小型香炉/供盘 | 月台东侧 | 礼仪与日常过渡 |
| 侧夹道 | 水缸、木盆、扫帚 | 西侧夹道靠墙 | 服务性杂物 |
| 后院 | 晾衣绳、鸡笼、鸡 | 后院东侧 | 家务与后院生活 |
| 廊后小院 | 现有水缸、盆栽保留 | 廊后小院 | 服务性小院 |
| 一进院 | 影壁前盆栽 | 影壁东侧 | 入口对景 |

阶段一控制在 **10–15 件陈设 + 3–4 类动物**，不追求数量。

### 3.3 动物清单

| 动物 | 数量 | 位置 | 表现 |
|---|---:|---|---|
| 猫 | 1 | 西游廊坐凳 | 蜷卧，静态 |
| 金鱼 | 3 | 院心荷花缸 | 静态/轻微摆动 |
| 笼鸟 | 1 | 西游廊鸟笼 | 静态 |
| 鸡 | 2 | 后院鸡笼旁 | 静态 |
| 鸽子 | 2 | 后院屋脊/檐口 | 静态（本轮未做，列为阶段二） |

阶段一不加入狗、马、羊等；狗可放在大门/外院，马骡在门外，不属于内院。

### 3.4 不做的事

- 不在厢房山墙 0.6 m 散水内放东西；
- 不在十字甬路、门洞、台阶、廊口摆大件；
- 不做大型假山、水池、曲桥——那是江南园林或王府花园，不是标准三进院；
- 不把鸡、柴垛放进二进院正院；
- 不一次做完整室内软装。

## 4. 验收与评估

### 4.1 技术验收

- `tsc --noEmit`、`pnpm build` 通过；
- 新增物件不悬空、不穿墙、不挡主路线；
- 大件陈设（鸡笼、坐凳、水缸）有碰撞，小件无碰撞；
- 优化后 draw call 不显著增加。

### 4.2 内容验收

- 从大门→一进院→垂花门→二进院→月台→前廊→侧夹道→后院，路线仍通畅；
- 院心、廊下、后院至少各有一个“生活焦点”；
- 动物可辨认，不追求写实解剖；
- 不出现“为填而填”的杂物堆。

### 4.3 评估问题

1. 院子是否从“样板间”变成“有人住”？
2. 物件是否有明确功能，而不是随机装饰？
3. 是否影响原有建筑阅读和漫游？
4. 哪些东西应留到阶段二，哪些应删掉？

## 5. 阶段二：室内与季节

- 室内：瓶花、盆景、茶具、书册、香炉、猫、鸟笼；
- 季节：石榴裂果、海棠果、落叶、晾晒物、荷花；
- 声音：蝉、鸽哨、鸟鸣、脚步、木门声；
- 微动画：猫尾、鱼游、鸽子点头、笼鸟跳动。

## 6. 阶段三：地域变体

### 江南园林/宅园

- 天井、白墙黑瓦、马头墙、四水归堂；
- 水池、太湖石、曲廊、月洞门、漏窗、亭榭；
- 宅园一体，轴线弱；常见“三进/五进住宅 + 侧花园”，花园是跨院，不计入“几进”。

### 山西大院

- 高墙、窄院、堡寨式门楼、单坡屋顶；
- 砖雕/木雕/石雕；多院并列，不是单轴多进；
- 乔家大院是多个大院/小院组合。

### 河南院落

- 中原窄长院、门楼、影壁、堂屋；
- 豫西窑洞、陕县地坑院；
- 康百万庄园是大型堡寨庄园，多院组合。

## 7. 技术组织建议

- 新增 `src/world/life.ts` 作为生活内容层，与建筑、绿化分离；
- 陈设/动物使用现有材质，避免新增贴图；
- 可复用内容做成函数：鸟笼、坐凳、猫、鸡笼、晾衣绳、水盆、扫帚；
- 大件加 AABB，小件不加；
- 后续地域变体复用同一套 content kit，只替换场景配置和建筑模块。


## 8. 阶段一撤销记录

阶段一曾加入坐凳、鸟笼、猫、金鱼、香炉、水盆、鸡笼、鸡、晾衣和盆栽，但评估后确认：

- 鸡笼、鸡、晾衣等偏“农家/服务院”，与官宦书香门第不协调；
- 猫、鸟笼、鱼缸、香炉虽可成立，但属于陈设层，不是用户要的“附属建筑/花园”；
- 已从场景中移除 `createLife` 调用，并删除对应截图。

后续内容方向改为：先做附属花园/跨院的空间方案，再决定是否恢复少量室内外陈设。
